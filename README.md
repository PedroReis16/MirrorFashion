# Mirror Fashion

Mirror Fashion é uma landing page para um e-commerce focado na venda de roupas.

![Pré-visualização do projeto](videos/project_preview.gif)

## Tecnologias utilizadas

- HTML5 e CSS3
- JavaScript

## Como executar localmente

1. Clone o repositório ou baixe o código:

```bash
git clone https://github.com/PedroReis16/MirrorFashion.git
```

2. Inicie o arquivo **index.html** diretamente no navegador de sua preferência
